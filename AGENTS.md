
## Orientações para o Projeto

- O Projeto Integrador IV tem como objetivo a aplicação de um processo de desenvolvimento de software, desde a concepção até a construção e liberação do software. O projeto, com tempo de trabalho previsto em 40 horas, visa integrar os conhecimentos e competências desenvolvidas no curso, em particular, conciliar o processo de desenvolvimento estudado em Processo de Desenvolvimento de Software (Scrum) com os métodos de manipulação de dados estudados em Consulta em Banco de Dados.

- O objetivo é criar uma situação de aplicação profissional, com vistas a desenvolver habilidades para o trabalho em equipe, considerando as competências e experiências individuais dos membros da equipe, além das capacidades de aplicação de uma metodologia para o desenvolvimento de software e manipulação de uma base de dados. Para o desenvolvimento dessas habilidades e competências, é necessário ter a compreensão de um problema para, então, especificar e desenvolver uma solução de software em conformidade com um processo que utiliza métodos, técnicas e tecnologias de desenvolvimento adequadas ao propósito da solução.

## Orientações Gerais para o Desenvolvimento do Projeto

- O objetivo do projeto é o desenvolvimento de um aplicativo que utilize alguma fonte de dados para processar e apresentar informações ou prover funcionalidades que possam beneficiar usuários, seja com aplicação em setores de negócios, meio ambiente, saúde ou bem-estar social. 

- O projeto deve ser desenvolvido com base no Scrum, de acordo com as capacitações desenvolvidas em Processo de Desenvolvimento de Software. A pesquisa em alguma fonte de dados é requerida para que possam ser aplicados os conhecimentos e capacidades abordados em Consulta em Banco de Dados. A equipe deve buscar alguma fonte de dados com a finalidade de obter, estruturar e manipular alguns dados que possam ser transformados em informações para o propósito do aplicativo a ser desenvolvido. Para esse fim, há vários portais e bases de dados disponibilizados abertamente com dados e informações sobre diversas áreas de aplicação.

- Este projeto integrador será desenvolvido em grupos, entre 5 a 7 estudantes, sendo que um dos integrantes deve exercer o papel de Product Owner, outro de Scrum Master e os demais de desenvolvedores, conforme estabelece a estrutura do Scrum. A finalidade deste projeto integrador é o desenvolvimento em equipes com base nos papéis da estrutura do Scrum, de maneira que não é possível o desenvolvimento individual, tampouco em grupos menores que 5 integrantes.

- **Observação**: Os grupos constituídos em projetos temáticos anteriores podem utilizar as definições de projetos já desenvolvidos (estudos de caso) para a realização do processo de desenvolvimento deste aplicativo, considerando o atendimento aos dois quesitos essenciais desta proposta do Projeto Integrador IV-A: seguir o processo com base no Scrum e a modelagem prevista nas duas entregas, e utilizar uma base de dados na qual possam ser aplicadas os métodos de manipulação de dados estudados nas disciplinas integrantes deste módulo.
